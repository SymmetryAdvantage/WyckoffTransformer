# WyFormer on hera

Hera uses the same Intel Xeon w7-3455 CPU and two RTX 6000 Ada Generation GPUs
as [Zeus](../zeus/README.md). Use the Zeus instructions through the references
below, with Hera's differences in [environment.md](environment.md) taking
precedence. Keep shared instructions in Zeus's pages.

| Task | Reference |
| --- | --- |
| Set up the environment or a worktree | [Hera environment](environment.md), then [Zeus environment](../zeus/environment.md) |
| Run training, generation or tests; choose GPUs and worker counts | [Zeus usage](../zeus/usage.md) |
| Diagnose environment or GPU problems | [Zeus troubleshooting](../zeus/troubleshooting.md) |
| Start an agent session | [Hera agent brief](agent_brief.md) |

Zeus's dated experiment results, active jobs, GPU occupancy and verification
records describe Zeus. Check Hera's current load before choosing resources.
